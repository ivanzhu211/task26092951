# alerttimeline

员工 Warning 告警的风险时间线库（Go，纯内存，串行调用，告警只增不撤销）。

## 规则

- 时刻 `t` 的计数范围：晚于 `t - 3600000` 且不晚于 `t` 的告警，即 `(t-1h, t]`。
- 窗口内告警数达到 3 时为 Critical，否则为 Warning；这是随时间变化的派生状态。
- 告警在自己的时间戳开始计数，恰好一小时后不再计数；同一毫秒内的到达与到期共同决定该时刻状态，不产生零长度区间。
- 每次查询都基于当前已接收的全部唯一告警按事件时间完整重算，与接收顺序无关；后到告警会改变过去的查询结果。

## API

```go
tl := alerttimeline.New()

// 录入告警。key 全库唯一：第一次写入生效，
// 后续相同 key（即使员工或时间不同）无副作用地忽略。
tl.Ingest("alert-key-1", "employee-42", timeMS)

// 查询员工在 [fromMS, toMS) 内的 Critical 最大连续区间。
// 返回 []alerttimeline.Range，左闭右开，已裁剪到查询范围并合并相邻区间。
ranges := tl.CriticalRanges("employee-42", fromMS, toMS)
```
